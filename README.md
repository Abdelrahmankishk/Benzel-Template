# Benzel Template - Bootstrap 5.3.5

A responsive, single-page creative agency website built using **HTML5, CSS3, and Bootstrap 5**. This project recreates a modern landing page with interactive elements, smooth transitions, and structured sections.

## ✨ Features

- **Responsive Navigation:** A Bootstrap-powered navigation bar with collapsible mobile navigation.
- **Hero Section:** An image carousel featuring multiple slides, introductory content, and call-to-action buttons.
- **About Section:** An introduction section featuring animated text using Typed.js.
- **Creative Team:** Team member profiles with interactive hover overlays and social media icons.
- **Services:** A structured overview of the services and capabilities offered.
- **Pricing Plans:** Four pricing tiers (Starter, Silver, Gold, and Platinum), with a highlighted best-value plan.
- **Customer Testimonials:** An interactive carousel showcasing customer feedback.
- **Contact Section:** A contact form interface alongside an embedded Google Maps location.

## 🛠️ Technologies Used

- **HTML5** – Structuring the website content.
- **CSS3** – Custom styling, animations, transitions, and visual effects.
- **Bootstrap 5.3.5** – Responsive layouts, grid system, components, and utilities.
- **JavaScript** – Interactive website functionality.
- **Font Awesome 6.5.1** – Icons and social media elements.
- **Typed.js 2.1.0** – Animated typing effects.
- **Google Fonts** – Poppins and Source Sans 3 typography.
